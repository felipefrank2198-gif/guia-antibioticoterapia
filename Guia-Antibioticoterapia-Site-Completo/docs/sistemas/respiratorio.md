# Respiratório
- PAC (adulto): Amoxi 1 g 8/8 h 5 d; Amoxi/Clav 875/125 mg 12/12 h 5 d; hospitalar: Ceftriaxona + Azitro; risco MRSA: + Vanco/Linez.; risco Pseudo: Cefepime ou Pip/Tazo (7 d).
- PAC pediátrica: Amoxi 40–50 mg/kg/dose 12/12 h 5 d; Azitro para atípico.
- HAP/VAP: Cefepime/Pip-Tazo ± Vanco/Linez. 7 d.
- Aspiração: tratar conforme PAC/HAP; anaeróbio se abscesso/necrose/empiema.
