# Sistêmicas / Imunossuprimidos
- Sepse sem foco: Cefepime/Pip-Tazo; choque/ESBL: Meropenem (infusão prolongada) ± Amicacina; MRSA: + Vancomicina (AUC); alto risco fúngico: Echinocandina.
- Febre neutropênica: baixo risco — Cipro + Amoxi/Clav VO; alto risco — Cefepime/Pip-Tazo EV; instável — Meropenem ± Amicacina ± Vanco; febre persistente 4–7 d — antifúngico empírico.
- Candidemia: Echinocandina → step-down Fluconazol (se suscetível) por ≥14 d após 1ª hemocultura negativa; remover CVC.
- Aspergilose: Voriconazol/Isavuconazol (6–12 sem; TDM/interações).
- PCP: TMP-SMX (TMP 15–20 mg/kg/d) 21 d ± corticoide; profilaxia com TMP-SMX diário ou 3×/sem.
