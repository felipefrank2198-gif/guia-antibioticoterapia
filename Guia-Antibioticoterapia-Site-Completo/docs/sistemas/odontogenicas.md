# Odontogênicas
- Dentoalveolar com sistêmicos: Amoxi 500 mg 8/8 h 3–7 d; falha: Amoxi + Metro 500 mg 8/8 h ou Amoxi/Clav.
- Sinusite odontogênica: Amoxi/Clav 875/125 mg 12/12 h 7–14 d; tratar dente de origem.
- Espaços cervicais/Ludwig: Ampi/Sulb EV; risco MRSA: + Vanco (AUC). Via aérea e drenagem primeiro.
