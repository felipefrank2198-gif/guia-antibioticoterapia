# SNC
- Meningite (adulto <50 a): Ceftriaxona 2 g 12/12 h + Vancomicina (AUC 400–600). >50 a/gestante/imuno: + Ampicilina 2 g 4/4 h.
- Corticoide: Dexametasona 10 mg 6/6 h antes/junto 1ª dose se pneumococo suspeito.
- Pediatria: Ceftriaxona/Cefotaxima + Vanco; + Ampi se risco Listeria (<1 m).
- Pós-neurocirurgia: Vanco + Cefepime/Meropenem.
- Encefalite HSV: Aciclovir EV 10 mg/kg 8/8 h 14–21 d.
- Abscesso: Ceftriaxona + Metronidazol (6–8 sem); pós-cirurgia: Vanco + Cefepime/Mero.
