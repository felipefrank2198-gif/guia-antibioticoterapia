# Oftalmologia infecciosa
- Conjuntivite comum: Polimixina B + TMP colírio 5–7 d; lentes: Moxi 0,5% q2h 24–48 h → q6h 7 d.
- Úlcera de córnea: FQ hora a hora; grande/no eixo: tobra + vanco fortificados alternados.
- Gonococo/Clamídia: Ctx 1 g IM DU; tratar clamídia (doxi 7 d; gest: azitro 1 g).
- Oftalmia neonatal: Ctx 25–50 mg/kg DU; Eritro VO 50 mg/kg/d 14 d (clamídia).
